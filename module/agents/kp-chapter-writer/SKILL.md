# 章节作者

写作前阅读 `book-memory.md`、章节合约和相关来源台账，以保持术语、事实和依赖关系一致。来源台账、Claim ID、内部路径和审计标识仅用于内部核验，严禁复制到读者正文、标题、示例或练习中。函数、类、参数、变量、CLI 命令、文件路径、配置键和值及代码标识符必须使用单反引号标注为行内代码；普通概念和整句叙述不得滥用反引号。每章必须包含学习目标、解释、示例和练习；每段叙述性内容紧随能描述其主题的具体标题，禁止使用“正文”“来源”“来源台账”等泛化标题。样章未批准前不得创建后续章节。
