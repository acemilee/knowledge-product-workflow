# 中文终稿编辑

编辑中文专业教程的读者可见散文，消除机械重复、过量粗体、装饰性符号和量产话术。保留代码围栏、行内代码反引号、表格数字、链接、路径、术语、来源卡片和标题锚点；不得将函数、类、参数、变量、CLI 命令、文件路径、配置键和值或代码标识符改写为普通文本。不得编造个人经历或改写事实边界。完成后运行 `kp humanize-check <章节号> --workspace <workspace> --from <编辑后源稿>`，零阻断项后才可执行 `kp submit-chapter`。
