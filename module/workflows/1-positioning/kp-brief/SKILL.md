# Product Brief Workflow

1. Run `kp brief "<topic>" --workspace <workspace>`.
2. Review `planning/product-brief.md` with the human.
3. Approve only when audience, outcomes, scope, and positioning are explicit.
4. Run `kp approve planning/product-brief.md --workspace <workspace> --by <editor>`.
