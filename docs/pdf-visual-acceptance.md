# PDF 视觉验收

新书的 PDF 使用受控 `knowledge-product-pdf-v6` 样式，而不是由宿主模型自由设计。v6 通过受校验的出版设计 token 选择视觉家族、色彩、标题尺度、行宽、段落节奏和运行页眉；它不接受原始 TeX、CSS 或外部模板。历史 v4/v5 书稿保持可渲染，不会被静默迁移。读者交付只包含 `delivery/book.md` 和按 Brief 要求生成的 `delivery/book.pdf`；QMD、TeX、过滤器、台账、审稿记录和运行日志均为内部工件。

## 固定视觉系统

- 封面展示主题、副标题、目标受众、版本、冻结发布日期、封面标签和版权行；页脚标签单独配置，不与封面标签绑定。
- 目录独立起页，显示“目录 / Table of Contents”，保留至多两级标题、页码和引导线。
- 标题、页码、页脚、来源卡片、提示框、表格和代码块都由固定模板渲染。
- A4 正文默认 12pt，也支持显式选择 14pt；使用 `extreport` 使字号真正生效。v6 左右页边距 13mm、上下页边距 18mm；旧 v5 默认左右 16mm，代码块按正文同步放大并强制长行折行。
- PDF 书签由 Markdown 标题生成；使用来源卡片时，PDF 必须保留可点击的 HTTPS 外部链接。
- 新书在 Brief 阶段创建 `planning/publication-profile.yaml`，默认封面标签和页脚标签为“知识产品工作流”、新书默认版权为“© {年份} 知识产品工作流”、版本为 `v1.0.0`。每次渲染会从该配置派生 `delivery/publication-metadata.yaml`；配置更新必须经受控预览和一次确认，旧 PDF/manifest 会归档。
- 出版设计经用户确认后，PDF 渲染会生成版本绑定页面预览集。自动规则只阻断空白页、预览失效、重复图注和确定性裁切/溢出问题；文字可读性、留白是否合理和视觉识别度必须由人工复核，不能由无视觉模型自动宣称通过。

## 可自定义的出版信息

用户可以独立修改封面标签、页脚标签、版权行、副标题、发布日期和书稿版本。推荐直接向宿主提出自然语言请求，例如：

```text
把封面标签改成“星云学院”，把页脚改成“仅供内部学习”，书稿版本升级一个 patch；不修改课程和正文。
```

宿主必须先展示预览并等待一次确认，再调用受控出版更新。确认后仅重建规范 Markdown、Quarto 源稿、PDF 和交付清单；不得让用户重走 Brief、蓝图、样章、章节、来源或审稿流程。封面标签与页脚标签可以不同，用户也可以保持其中任一字段不变。禁止直接编辑 TeX、Lua、QMD、交付清单或 `publication-profile.yaml` 来改变视觉效果。

## 允许的正文组件

```markdown
::: {.kp-source}
来源：[机构或文档标题](https://example.com/documentation)
:::

::: {.kp-key-takeaway}
关键结论：用可验证的工件交接阶段结果。
:::

::: {.kp-practice}
练习：为自己的项目列出一个可验证的交付条件。
:::
```

裸 `{.kp-note}`、`{.kp-key-takeaway}` 等字符串不是合法组件，禁止写入章节。汇编后的 `book.md` 不保留 `.kp-*` 或 `:::`；只有 `book.qmd` 保留合法 fenced div 供 PDF 过滤器使用。

普通 Markdown 标题、表格和带语言标签的 fenced code block 均受支持。不要在读者书稿中写原始 TeX、HTML、来源台账、Claim ID、审稿批次、哈希或运行路径。

## 插图规则

- 将读者图片放在书稿工作区 `assets/`，正文使用相对路径，例如 `![流程图](assets/workflow.png)`。
- 仅允许 PDF、PNG、JPG/JPEG。SVG 可保留为创作源，但必须先转换为 PDF 或 PNG 后再进入正文。
- 禁止远程图片、`file:` URI、绝对路径、`..` 路径逃逸和不存在的资源。
- 插图必须服务于概念、流程、对比或案例讲解，不能仅用于填充页数。

## 发布前检查

1. 运行 `kp assemble`，确认生成 `book.md`、`book.qmd`、出版元数据和当前 profile 的样式资产。
2. 运行 `kp render-pdf`，确认 PDF 与当前预览清单已生成。渲染日志写入内部 `runs/pdf-render.log`；出现 `Overfull \\hbox` 或 `Overfull \\vbox` 时渲染会直接失败。PDF 已存在但预览缺失、损坏或过期时，按 `kp status --json` 执行 `kp repair-pdf-preview --workspace <workspace>`，不反复校验或更改出版信息。
3. v6 先执行 `kp audit-pdf-visual`，通过预算授权后由 `kp-visual-reviewer` 查看高分辨率抽样并执行 `kp record-pdf-visual-observations --from <观察输入>`。失败项按责任 Skill 修复，重新生成当前报告。随后人工查看当前版本的封面、目录和正文样张：文字不重叠、表格与代码不越界、图片不截断、页码和页脚稳定、无异常空白页。用户确认后，由根 Skill 执行 `kp record-pdf-visual-review --workspace <workspace> --by 用户`；该命令只记录当前 PDF 与已有预览的绑定，不重新生成页面图片。
4. 运行 `kp validate-delivery`，确认页数、书签、来源外链与视觉复核的当前绑定。PDF 或预览变化后旧复核失效，先修复派生物并重新展示页面。
5. 运行 `kp publish` 后，只将清单中列出的最终 Markdown/PDF 交付给客户。

## v6 量测与判断边界

v1.3.1布局2默认正文12pt：中文正文PingFang SC，中文标题/强调显式映射PingFang SC Semibold；英文正文Inter，代码/等宽标识JetBrains Mono。缺默认字体时明确阻断，不静默改用其他字体。用户明确选择font_policy=fallback时才使用SimHei、Latin Modern Sans/Mono；旧布局1保持原字体。标准标题尺度为章22/30pt、节15/21pt（字号/行高）；正文relaxed为1.40行距倍率、段间4pt。目录保留原层级和独立页，消费共同字体角色。实际PDF嵌入字体与页面仍须复核。

代码自动折行的↪提示保留；进阶读者需理解其非源码含义。用户已决定本版跳过整段代码复制安全专项，不把这项列为v1.3.1新增阻断，也不宣称整段复制可直接执行。

默认橙色强调 B65E2B、浅底 F8EBE2；紫色强调 6847A5、浅底 EEE8F7。用户通过 Brief 的品牌色意图确认，出版设计预览同时展示编号、表格、提示框和图型示意。合法 HEX 必须满足色板对比度；视觉家族不覆盖用户品牌色。

2026-10-13 · v1.3.4修正0.8规则版本为`kp-pdf-v6-visual-5`，量测修订2。普通正文中位字号低于10pt阻断、低于11.5pt预警；目录低于9pt阻断、低于10pt预警；代码／图／工作表低于8pt阻断、低于9pt预警。五列以上表格、过长行、异常正文占用率和嵌套图文本触发成页核验；阈值不表示审美已由算法证明。

全书量测与160dpi清晰图分别留证。CLI不传--sample-limit时覆盖当前PDF全页；显式正整数预算仅供初查，库默认抽样及布局2短书全覆盖保留。封面、末页及可定位异常页必选，超过普通预算也不截掉。最终全书须全页清晰实际passed，或本人明确确认完整当前PDF的既有manual-coverage原话记录；抽样和截图生成不算全书通过。报告沿现字段绑定PDF、预览、profile、图源、页集合、DPI、PNG及观察事件，不增加证明字段。规则刷新使旧报告不算当前，但实际相同输入与相同页图的观察可复用，failed保持；缺图只补缺项，渲染失败保存完成页及缺项，不写全书通过。

嵌套矢量 Form 的文本变换无法可靠逐字恢复时，不用重复回调推导错误的小字号，报告明确要求查看实际图字。栅格清晰度、表格拥挤、合理留白、整体配色和浏览负担需要页面观察及用户判断；截图生成不等于复核通过。失败观察进入 `pdf_visual_repair_pending`，不能用人工回执覆盖确定性 blocker。

受控插图四步为：教学目的与语义输入 → 固定 D2/SVG 图型和批准色板 → 精确文本及 PDF/PNG 双格式资产 → 成页核验。v6 提供层级架构、左右对比、嵌套结构、卡片矩阵、阶段流程；已有流程/时序/生命周期仍使用 D2。正文语义与图位置改变后刷新编辑证明及图资产；纯色板更新受控重建图与书稿，不修改章节内容。

v1.3.1宿主生图扩展消费同一教学语义，有限架构/层级/分支流程三图族使用正式母版、精简预算与资产风格证明；图包装为PDF仍是位图。纯换色时矢量可重渲染，位图必须按原槽位申请实际调用，不能自动绕过预算。新阅读布局2提供章导读、H2双细线、品牌代码/列表和短代码块分页保护；旧布局1使用固定旧资源。详见[受控插图与阅读布局](controlled-illustrations.md)。


## v1.3.3 阅读结构与成页

教学Rubric2新增六项实际语义观察与阅读索引，记录比较单元依赖。课程/内容计划说明各章独立贡献；重复例子要新增条件、任务或支持独立操作，示例/图表与解释互补。编程、策划和定量主题按读者任务选择不同形式，必要推导可以连贯。结构审核通过不代替清晰成页与用户判断。

短行内代码按当前字宽与可用整行宽度使用完整圆角浅框，超长串保留自然/兜底断点，数据空格输出真实字体空格；不逐字增加内边距。小结果表靠正文轴对齐，来源说明低于主要结论的强调程度；实际字号、品牌与公式角色保持。各类图文组合、长表续接和标识边界继续真实渲染验证。

文本token预算门已于2026-10-07按用户决定取消；无全书／章节／动作额度、预警线、预算预约或追加预算审批。写稿和审核按批准教学目标负责内容质量，实际缺项与用户审批继续阻断交付。旧文本账本保留历史，AI生图调用次数规则保持独立。

具体学习成果写入正式Brief，而非临时运行备忘。公开输入见brief-schema；同次presentation预览能确认封面、品牌和后端。cover_title_lines保留题目及词间空格，封面2版权/梗概在预览阶段预检。

结构指标仅定位warning；实际语义审核用developmental-review-template/record-developmental-review，绑定当前稿件、合约及实际依赖。并列、步骤、因果、完整示例分别组织，不规定列表／图数量，不使用已取消的文本预算门。

行内代码以品牌浅底和安全断点排版，斜杠等优先；独立长数据在块级处理，RawInline不能注入段落。标题空间即时判断，合法长表续页表头保留；示例、短列表与末段/来源按当前字体与宽度估算可读组合，不缩字号凑页。字体角色中位值分别记录；跨列片段按位置区分，可靠性不足仍清晰看图。

图失败时正文检查点可以推进独立后续章。render-review-preview只输出runs下的完整诊断预览，待办位置明确、未发布；不能覆盖delivery或通过正式发布门。新文本账本总额内预留必要收尾，不以动作改名借用。最终视觉回执仍必须来自当前PDF的真实用户。
# v1.3.3 混排角色与外侧间距补充

普通教程不生成固定“定义依据／检查依据／判定依据”或官方/作者身份声明，来源与事实核验留在后台。当前正文变更必须走受控作者修订，不靠隐藏PDF内容实现。

布局2保留PingFang SC Regular/Semibold、Inter、JetBrains Mono和Latin Modern Math；明确锁定基础缩放。正文12 TeX pt约为11.955 PDF pt，代码字级保持已认可配置；分式和上下标结构另核，不能把总高度当普通字级。报告`typography_measurement_revision=1`覆盖CJK/Latin/InlineMath角色检查，旧缺项报告仍可读取但不算当前通过。

普通文本与英文/数字/行内数学有0.25em外侧留白，已有空格不重复累计。只改AST外部边界，代码、路径、URL目标与Math payload保留。通过原生ActualText保持字体私用字形别名对应的输入字符；实际看图和可靠文本提取都必须通过。

已声明的正文角色可靠偏离目标是阻断，不能由全页median≥10pt或用户回执覆盖。自动量测不替代当前高清观察；图内/嵌套缩放不可靠时明确待核。参见`tests/test_mixed_typography_v133.py`、`tests/test_visual_audit.py`及既有冻结阅读回归。

当前量测修订为2：字体切换后出现归零文本矩阵时，不把缺乏可靠位置的页眉／页脚聚合片段当正文角色证据。真实小字号与行内公式基准漂移仍阻断；不能由人工通过覆盖。重算量测时，只有PDF、出版设计、资产输入及逐页像素完全相同时才能复用已有实际观察，明确failed原样保留。

收尾按阅读任务组成有限组合：验收短表与核对段、字段约束列表与章末自检。表格量测使用实际列宽、字体和既有最小行高；超过一页的长表继续正常分页及重复表头。文档末尾的空参考文献容器不代表新的教学内容。后续章节、文档末尾及紧凑／宽松段距均需原生回归，不用减少字号、删数据或固定页数消除尾页。
