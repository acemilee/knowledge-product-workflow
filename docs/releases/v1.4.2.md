# v1.4.2 发布说明

2026-10-20。本次发布以已经部署的公开核心 r0.2 为基底，补齐公开发布检查，并修复全库检查发现的旧Brief兼容缺陷。软件包版本为 `1.4.2`，r0.2仅表示施工计划修订号，不是额外的软件版本。

## 发布内容

- Python CLI、模板、测试和宿主集成源码，遵循根目录 Apache-2.0 许可证；第三方参考材料保留自己的许可证。
- 14个公开 Skill，根入口仍为 `kp-create`。
- 包含旧Brief兼容修复的 Python wheel，以及独立公开 Skill ZIP 和 SHA-256 校验表。
- 本次以单个公开快照更新主分支，不导入本地尚未推送的开发提交历史。不包含闭源参考创作扩展、个人配置、书稿、日志或未验收的r0.3修改。

## 主要改进

1. 教学取向区分方法实践、实现和混合教程。方法课优先保留完整提示、输入输出、失败对照和迁移练习，完整程序可放入经实跑与交付校验的配套资源包。
2. 作者和编辑在原有流程中检查教学层次、内容节奏与读者工件，不新增固定协调角色。
3. 修复长行内代码和高亮代码的断行，保留原始内容、字号和长表分页；本地编译默认300秒，可显式设置且上限600秒。
4. 模板与命令发现使用实际输入模型，减少首次执行猜测；视觉报告读取避免同一命令内重复解码，不跨命令缓存通过结果。
5. 继承提交回执恢复、局部证据复用、交付前检和版本绑定的最终质量门。

## 验证范围

发布基底为本地已验证提交 `d23abea6d45900d2885426d04aac5c9420f0523f`。97个运行文件中，仅旧Brief解析器有逻辑修正：缺少后来新增的“产品定位”栏目时沿用旧版缺省值；显式空值及非法教学取向继续拒绝。Skill功能和出版模板保持r0.2，r0.3不在发布范围。新wheel按修复后的源码重建，不能与原部署wheel混称。

- 97个运行文件与发布wheel逐字节一致；与原部署基底比较，仅旧Brief解析器有逻辑差异，另有仓库换行规范化。公开Skill包57个文件与冻结公开包一致。
- 原轮受影响资源、旧契约、快照、CLI及模板检查通过；各组有重叠，不累加为全库测试总数。
- 空上下文作者与编辑完成两种题材短样章，另有独立读者迁移验证；不能推广为真人全书学习效率结论。
- 最终11页真实PDF检查了长路径、CSV、JSON、中文数学、窄表和合法续表；软件检查不代替产品用户批准。
- 固定Ruff历史基线为19项，本轮零新增；全局Ruff并非零问题。CI按文件、规则、消息和原语句的多重集拒绝新增，不自动刷新基线，不忽略重复问题；全库测试检查保持。

首次公开CI为1703通过、59失败、38跳过。逐项归因为2项旧Brief兼容缺陷、8项旧测试契约失配、22项synthetic插图替身未隔离字体前提，以及27项缺真实原生依赖；原失败记录保留。发布修复更新测试去调用真实交付QA，继续验证最终uncertain、归档篡改和读后变更拒绝，不回退生产质量门。

真实Poppler、D2、浏览器导出、Quarto、XeLaTeX及合法首选字体不足时，对应原生测试明确标为未执行，并打印原因；依赖齐备时原断言照常运行。纯软件拒绝路径继续执行，skip不等于原生通过。未变的出版模板沿用r0.2原轮原生验证，不以无授权字体的云端环境冒充默认排版验证。

同协议单样本的128/190页视觉报告读取中，PNG解码次数均减少50%，该路径耗时约减少45%。这些数据不代表整书生产、Token或费用同比下降，也不是统计显著性结论。

## 已知限制

- 正式并行继续关闭。真实宿主4～6并发资格和大规模性能验收仍待完成，离线调度验证不替代真实资格。
- 本次不包含r0.3计划中的新默认版权/空页脚、主题短语标题引导、普通读者文档声明或新增批量检查入口。
- 自动受控程序实跑仅支持Python；其他语言不得标为已经实跑。
- PDF工具链和字体由用户在本机合法准备，字体文件不随包分发。Windows是当前经过完整验证的平台。
