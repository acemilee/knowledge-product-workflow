# v1.4.2 r0.4：目录语义、主题覆盖与蓝图呈现修正

2026-10-21。公开标签为`v1.4.2-r0.4`；CLI、wheel和14个公开Skill的内部版本仍为`1.4.2`。请以本标签和SHA256SUMS区分修订，旧Release、标签和附件保留。

## 修正内容

- 新蓝图显式记录`title_style`，逐章/节声明中心、覆盖主题和读者任务；默认以具体统摄中心命名，由子节展开内容，不把教学过程句或完整覆盖清单搬进目录。
- 新增只读`outline-view`，提供`toc`纯目录、`design`设计说明、`review`主题/改名对照。正式标题不再夹带权重、体裁与解释尾巴，完整设计信息仍保留。
- `amend-outline --titles-only`在任何归档前拒绝实际非标题变化，避免改名时暗改范围、目标、权重、依赖或图任务；模型规范化减少默认字段的误报。
- Skill与Schema区分中心和覆盖：必要比较、长术语及具体操作可以保留，不按字数或连接词计数判断质量。已有当前模板直接沿用，同工作区视图顺序读取，减少无效创建和忙锁。
- 旧蓝图缺意图字段时保持序列化兼容并标记`legacy_unknown`，不补假通过、不自动迁移或改名；现有蓝图审批和下游标题精确匹配保持。不增加常驻协调角色、逐标题模型调用或审批点。
