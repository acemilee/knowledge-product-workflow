# v1.4.2 r0.3：导航、读者资源与流程开销修正

2026-10-20。公开标签为 `v1.4.2-r0.3`，用于区分此前已发布的 `v1.4.2`。CLI、wheel及14个公开Skill的内部版本仍是 `1.4.2`；r0.3是本轮工程修订号。原Release、标签和附件保留，新修订以本页及SHA256SUMS识别。

## 修正内容

- 内容计划按完整依赖字段比较，合法列表调序不再误拒；新提交仍区分未知依赖与明确空依赖，并核对小节归属。已填写计划保留，只刷新派生指引。
- 普通模板、说明及数据通过 `reader_files` 显式声明，纳入可移植ZIP和交付清单；支持中文、空格、括号和锚点的本地链接。`reader-resource-preflight` 一次报告缺项，避免在编译后逐项发现。
- 程序执行证明明确实际默认入口及参数范围；默认成功不升级为全部模式已验证，离线mock不代表真实训练。
- 同一命令复用资源闭包、证明派生和路径解析；写前、退出、实时锁、路径归属和字节漂移检查保留。新增 `check-chapters` 批量一致快照检查，exit 0不等于全部章节已通过最终质量门。
- 修订动作覆盖完整控制收尾，明确缺文件、权限、共享冲突、活跃锁及未知身份；显式原操作查询优先，避免重发未确定动作。
- 主题短语标题引导前置到蓝图批准前，任务动作保留在学习目标、reader_job和导读；词法候选不代替语义判断，不在出版层截字。重复边界声明只提供限量、冻结、带范围的编辑建议，不自动删句或重审全书。
- 新书默认右页脚为空，居中页码保留；封面默认版权为“© 出版年份 葬爱西兰花”。旧书保持原配置，仅显式更新。
