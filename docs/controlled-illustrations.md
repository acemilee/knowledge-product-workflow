# v1.3.1 受控插图与阅读布局

CLI管理准入、调用凭证和资产证据，实际生成由宿主工具完成。宿主有参考图输入能力时，可使用正式包的母版；没有该能力时不能宣称达到同等插图风格。当前支持受控宿主PNG、D2及固定SVG，不包含完整Excalidraw或付费模型API适配器。

## 生产顺序

1. Brief确认品牌与出版预览，默认橙色；新书使用阅读布局2。插图风格修订1消费固定母版和架构、层级、分支流程三个图族。旧布局1继续使用原资源，升级前先补普通章导读。
2. 内容计划明确读者任务。只有空间关系、层级或分支/回路需要图时才准入；线性步骤用列表，精确属性用表格。图的标签、边及证据边界先冻结。
3. `kp illustration-schema`和`kp diagram-schema`公开字段。`freeze-illustration-budget`冻结预算，`illustration-preflight`返回凭证、已落盘提示词与当前工作区参考。用户指定型号必须与宿主实际能力一致，未知型号不能冒充image-2.5。
4. 调用前记录`dispatched`，宿主仅发送一次；实际返回PNG保存在书稿内后记录`completed`。随后`submit-illustration`绑定原图并包装成PDF；原位图没有变成矢量，也没有识别出实际字体文件。目标尺寸/质量与实际回执分开记录。
5. `illustration-style-template`给出资产检查输入指纹；先消费`kp-visual-reviewer`的token预约，再用`record-illustration-style-check`记录九项观察。文字、关系或明确风格失败阻断章节；主观待决允许取得成页证据，最终由用户明确解决。
6. 图引用、正文全部定稿后跑发展性与humanize两份证明，再提交章节。图后展开解释、清单或精确表格；不要把整节长文堆在图前。移动引用属于正文变化，刷新正文与资产绑定；语义和风格未变无需再生图。
7. PDF生成后运行`audit-pdf-visual`、实际查看清晰页图、记录模型观察、展示当前PDF，再取得当前用户视觉回执，执行交付校验与发布。测试用户回执仅用于隔离测试。

## 默认预算与恢复

旧政策1兼容模式每章1槽、全书6槽、每槽最多2次发送，串行1；新政策2以以下任务驱动规则为准。失败、超时和编辑占尝试；未发送预约可取消。改ID、改色、移章或换模型不能重置历史；共享AI风格板占全书槽。复用正式母版没有新增生成调用。

`illustration-budget-status`查看当前消费。`unknown`先核对服务是否已返回，保留费用预约；不能盲目重复发送。明确失败可在原槽位指定`--repair-reason`纠正一次，耗尽后保持未通过并返回预算/范围选择。费用未知写`unavailable`，不写零账单。货币上限另需价格版本、币种及单次预约；原生宿主不暴露收费信息时只核验调用/槽位，不换算订阅美元费用。

缓存键包括语义、风格/参考、品牌、后端/可知型号与尺寸/质量。无关正文修订只刷新绑定；资产或样式变化会失效对应证明。矢量换色可受控刷新，宿主位图换色仍需原槽调用额度，不能把旧颜色图混入新品牌交付。

## 公开输入与证据边界

`kp token-action-schema`公开模型动作预约字段；`kp publication-schema`公开出版更新字段；完整命令索引为`kp commands --all --json`。正文页数用`target_pages: "正文 1-2"`，排除封面与目录。

初始未批准Brief收到修改意见用完整输入重新运行`brief`，已批准Brief使用`amend-brief`。待审批蓝图被当前Brief内容修订失效时，使用`amend-outline`归档并重新绑定，禁止先批准旧蓝图。CLI生成模板中的旧绑定字段由控制面重绑，宿主不手改hash。

位图字高可通过审阅者标注的文字区域只读量测；字高不是排版字号或字体身份。15%偏差进入复核，25%可信量测偏差阻断；字形、几何、配色及信息密度仍须实际看图。PDF文本提取、图内文字和长行统计可能不可靠，自动指标不能代替当前成页复核。生图风格承诺由“冻结约束、实际观察、失败阻断、有限修复”共同成立，不能保证每次随机生成必然成功。

## v1.3.2候选

Brief阶段先按宿主选择链路：Codex订阅认证、当前GPT模型、实际原生生图/参考能力均可核实时，同次确认是否使用host-image；其他Agent（如DeepSeek harness）、API认证、非GPT或能力未知时默认vector。明确但不支持的AI请求须解释限制并取得可执行选择，不静默改写。工作流不配置生图API Key、外部API或生图MCP。新书配置在确认前保持vector，确认AI方案后由受控出版预览记录illustration_backend_preference=host-image；风格2生图预检在预约前检查该选择。宿主资格由Skill核实，CLI不能独立读取账号订阅或验证GPT身份。

新政策2图数来自批准教学任务，首次N/无消费书最多2N，已有消费修订按C＋R；旧政策1及研发验收历史仍保留原上限。新发送必须先预约并dispatch一次，缓存命中不发工具；unknown未结算阻断新预约，订阅额度/限流错误立即停止，不自动重发或换模型。图次数耗尽时停止自动分支，返回具体未通过项；不重复审同一输入或换工作区清额度。文本token额度门已取消。原生图像token未知时不能准确封顶整个订阅账户实耗，工作流控制调用次数和可登记预算。

三套有限配色按教学任务选择，同概念跨图同色。图级输入presentation由Schema公开，不能手改签名登记。风格2宿主须支持首次两参考及纠正三输入；颜色卡为确定性资产，无模型调用。update-diagram-presentation冻结候选，style模板/观察带candidate_call_id，检查后activate-illustration-candidate切换，失败不会覆盖旧合格图。软件使用候选中性母版时最终用户认可仍待取得。

新版封面cover_layout_revision=2采用中文梗概、可选英文梗概/学习重点/内容说明，日期年月，署名仅版权行一次，无语言栏和开发说明。原始出版日期和正文页脚保留。旧布局1资源不改。四个出版模型同步传递新字段，渲染只读取锁定文案。


候选母版与当前PDF一并展示并获用户明确认可后，才可由根使用 `record-pdf-visual-review --confirm-style-anchor`；回执绑定当前母版hash，不改图文件或签名历史。只批准PDF不能冒充母版认可，候选资源尚未获认可时不能正式发布。

新版vector使用冻结图幅的整版可读宽度；三个或四个分区的D2 flow使用有限两行布局与关系标签留白，保留所有声明边。D2网格跨单元边不是自动避障，必须实际检查。[D2网格说明](https://d2lang.com/tour/grid-diagrams/)

代码块单独使用1.10行距，正文行距不变；图注及图文间距使用有限参数。不得把资产高分辨率当作成页图字达到9pt。

token预约只有宿主确认尚未执行时，才可以 `cancel-token-action --reason` 取消；不伪造0用量，不删除历史，已完成/失败不可退款。输入版本已变的旧预约不会成为当前视觉证明。


风格2资产量测revision2会用当前PNG实际宽度与冻结planned_width_mm折算单行中文字可见笔画pt；低于9pt先阻断，不因相对母版偏差未超过25%而放行。深色笔画使用亮度阈值，混合/多行框不能套单行硬门。独立审阅须包含最小说明和连线文字，不能只量大节点；最终实际页面仍另核。旧量测证明需用已有原始观察数据受控重算，不改消费历史或冒充新模型零费用。


## 政策2：任务与位置

新蓝图模板显式illustration_policy_revision=2，旧输入缺字段为1。每小节明确必要/有益/不画及具体读图问题/视角/组织增益/替代评估；数量不按章/页/书配额，普通短操作及参数仍优先原生列表/表。只制作选中的图任务，引用已有图可回看小节，不新获调用。

任务随蓝图同次预览和批准、派生合约，再由章节内容计划细化。主要asset_decision为表/工作表也可有多个独立图任务；实例顺序、正文锚点与task_id对应。diagram-template --task-id给当前paragraph_anchors，取返回值作after_anchor/before_anchor，受控更新草稿计划；插入幂等且不在代码/框内部。锚点缺失先修当前计划，不猜页码或偏移。

freeze-illustration-budget读取批准蓝图的实际host-image制作任务，不接受任意N扩额；旧预约在计划过期/任务停用后拒绝dispatch。C包含所有已发送历史，R是当前任务各自两次内的剩余尝试；停用不退款，N=0旧书保留消费账本。机制总览仅政策2/风格2的hidden_mechanism/synthesis三至六阶段链准入，不开放自由AI图族。

纯vector/无图书只做自己的成页门，不能被目录旧AI文件或风格2字段触发母版审批；实际host-image引用才绑定候选母版确认。审批元数据不改变图像或新政策的视觉缓存，最终PDF/母版用户判断不代签。

布局2的教学图使用有效百分比宽度、145mm默认高度上限并保持等比例，避免纵向图被放大成整页；长行内代码显式保留原始数据空格。旧layout1资源保持。

已有受控组件、目录或样式文件确实与当前规范包资源不同，`update-publication`可以保留相同可见配置来预览并修复渲染资源；资源健康的无变化更新仍拒绝。此路径不改正文或版本，不增加生图额度，也不能替代失败资产的风格证明。
